      Wiring

      Drag from one connector dot to another to run a cable. Drag a device by its header to arrange the diagram. Drag across empty space to select the cards and cables the box touches (hold Shift to add to a selection). Drag any selected card to move the whole selection. Delete removes the selected cables. Click a single card to edit its connectors.

      Estimates run each cable along the nearest side of the rack, up or down at 1.75 in per U, plus the service loop at both ends. Cables on the same shelf use the direct distance between connectors. Use Slack adj to add or remove length on one cable, or Override to set it yourself.
